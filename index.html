What is GitHub? What is a repository?

GitHub is a platform where developers can store, manage, and share their code. A repository (repo) is like a project folder on GitHub where you can keep your files, code, images, documentation, and other project files. In this guide, you will learn how to create a GitHub repository and upload your project to it.

Step 1: Create a GitHub Account

  1. Open GitHub in your web browser.

    2. GitHub is a platform where developers can store, manage, and share their code. Visit GitHub

  2. Click Sign up.
  3. Enter your email address.
  4. Create a password.
  5. Choose a username.
  6. Complete the verification steps.
  7. Verify your email address if GitHub asks you to.
  8. Log in to your GitHub account.
After logging in, you will see your GitHub home page.

Step 2: Create a New Repository

Now you can create your repository.
  1. Log in to GitHub.
  2. Look at the top-right corner of the page.
  3. Click the + button.
  4. Select New repository.
You will now see the Create a new repository page.

Step 3: Enter the Repository Name

1. You need to give your repository a name.
2. For example, if you are creating a website about HTML:
3. html-tutorial-website
4. Choose a short and meaningful name.

Good repository names

  • my-portfolio
  • html-tutorial
  • github-guide
  • weather-app
  • calculator
  • my-first-website
Avoid using unnecessary spaces or very complicated names.

Step 4: Add a Description

GitHub also allows you to add a description.

For example:
A beginner-friendly website that teaches HTML and GitHub.
The description helps other people understand what your project is about.
This step is optional, but adding a description is recommended.

Step 5: Choose Repository Visibility

GitHub gives you two main options.

Public

A Public repository can be viewed by other people.
Choose Public if you want to:
  • Share your project
  • Build a portfolio
  • Show your code to other developers
  • Submit your project using a GitHub link

Private

A Private repository can only be accessed by you and people you give permission to.
For a personal project that you don't want others to see, choose Private.
For a portfolio or tutorial project, Public is usually a good choice.

Step 6: Add a README File

You may see an option called:

Add a README file

A README file explains what your project is about.

For example:

# My First Website

This is my first website created using HTML and CSS.

For a new repository, it is useful to add a README file.
Select:

Add a README file

Step 7: Choose a .gitignore File

You may also see:
Add .gitignore
A .gitignore file tells Git which files should not be uploaded to GitHub.
For example, some projects contain temporary files or secret files that should not be uploaded.
If you are creating a simple HTML/CSS website, you can usually leave this option as None.
If you are using a specific programming language or framework, you can select the appropriate .gitignore template.

Step 8: Choose a License

GitHub may also show a License option.
A license explains how other people are allowed to use your code. If you are just learning GitHub and don't know which license to choose, you can leave it as None for now.

Step 9: Create the Repository

Now check your repository settings.

You should have something similar to:

Repository name:
my-first-website
Description:
My first website created with HTML and CSS.
Visibility:
Public
README:
Enabled

When everything looks correct, click:

Create repository 🎉

Your GitHub repository has now been created.

Step 10: Open Your Repository

After creating the repository, GitHub will take you to your repository page.

You will see your repository name at the top.

You can now store your project files inside this repository.

Step 11: Upload Your Files

If you already have files on your computer, you can upload them.

For example, your website might contain:
my-website/
│
├── index.html
├── style.css
└── images/
    └── developer.png
To upload them:
  1. Open your GitHub repository.
  2. Click Add file.
  3. Select Upload files.
  4. Drag your files into the upload area.
  5. Wait for the files to finish uploading.
  6. Scroll down to the commit section.
  7. Click Commit changes.

Your files will now appear in your GitHub repository.

Step 12: Understand "Commit"

A commit is basically a saved version of your changes.

For example, you upload your website and write:

Initial website upload

Then click Commit changes.

GitHub records that change.

Later, if you change your website, you can make another commit:

Updated homepage design

This allows you to keep track of changes to your project.

Step 13: Connect Your VS Code Project to GitHub

If you are using VS Code, you can connect your local project directly to GitHub.

First, open your project folder in VS Code.

Open the VS Code terminal:

Terminal → New Terminal
Then run:
    git init

This initializes Git in your project.

Step 14: Add Your Files

Run:

    git add .
The . means to add the files in your current project.

Step 15: Create Your First Commit

Run:

    git commit -m "Initial commit"

This saves your current project as a Git commit.

Step 16: Connect Your Local Project to GitHub

Go to your GitHub repository.

Click the Code button.

Copy the HTTPS repository URL.

It will look similar to:

    https://github.com/USERNAME/REPOSITORY.git

Then return to VS Code and run:

    git remote add origin https://github.com/USERNAME/REPOSITORY.git

Replace the URL with your own repository URL.

Step 17: Rename Your Branch to Main

Run:

    git branch -M main

This makes your main branch called main.

Step 18: Push Your Project to GitHub

Finally, run:

    git push -u origin main

Git will upload your project to GitHub.

You may be asked to authenticate with GitHub.

After the upload finishes, refresh your GitHub repository page.

Your project files should now be visible.

Step 19: Update Your Project Later

Whenever you make changes to your project, use:

    git add .

Then:

    git commit -m "Updated website"

Then: 

    git push
This uploads your latest changes to GitHub.
Complete Git Command Sequence
  • git init
  • git add .
  • git commit -m "Initial commit"
  • git remote add origin [repository-url]
  • git branch -M main
  • git push -u origin main

Remember to replace:

    https://github.com/USERNAME/REPOSITORY.git
with your own repository URL.

Important: Don't Upload Secret Information

Never upload passwords, API keys, private keys, or other sensitive information to a public GitHub repository.

For example, don't put something like this directly in your code:
    API_KEY = "my-secret-api-key"

Use appropriate environment variables or secret-management methods instead.

How to Find Your GitHub Repository Link

Open your repository on GitHub.

Click:

Code → HTTPS

Then copy the URL.

It will look similar to:

    https://github.com/your-username/your-repository

You can share this URL with other people.

Final Result

After completing these steps, you will have:

  • A GitHub account
  • A GitHub repository
  • Your project files stored on GitHub
  • A commit history
  • A repository URL that you can share
  • The ability to update your project using Git and VS Code
Conclusion

Creating a GitHub repository is simple once you understand the basic steps.

The basic process is:

Create GitHub account → Create repository → Add files → Commit changes → Connect VS Code → Push your project

Once you learn these commands, you can use GitHub to store and manage almost any coding project.

Frequently Asked Questions

What is a GitHub repository?

A GitHub repository is a place where you can store, manage, and share your project files, code, documentation, and other resources.

Is creating a GitHub repository free?

GitHub provides free repository options. You can create public repositories without paying for the basic GitHub repository functionality.

Can I upload HTML and CSS files to GitHub?

Yes. You can upload HTML, CSS, JavaScript, images, and other project files to a GitHub repository.

Can I connect VS Code to GitHub?

Yes. You can use Git commands in the VS Code terminal to initialize a project, create commits, connect a remote GitHub repository, and push your files.

What is the difference between Git and GitHub?

Git is a version control system used to track changes in your projects. GitHub is an online platform that provides hosting and collaboration features for Git repositories.
